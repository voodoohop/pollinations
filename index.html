LLM Voice Lab

Four tools about the LLM voice — the recognizable way language models write: load-bearing tapestries, rule-of-three everything, corporate smoothness without soul. Detect it, compare it across models, guess it against real humans, and strip it out. Inspired by Martin Fowler's LLM Voice bliki. Model calls run on your own Pollen.

Scan a text for the machine voice

Paste any text — a LinkedIn post, an "helpful" explainer, your own draft. The heuristic scan runs entirely in your browser: regex markers, rhythm statistics, formatting density. No API needed.

Deep analysis reads style-level markers regexes miss: clichéd extended metaphors, soulless smoothness, uniform rhythm of ideas, summaries nobody asked for.

One paragraph, three voices

Send the same request — "rewrite this text in your natural voice, same meaning" — to three models in parallel, score each rewrite locally for LLM voice, then let a fourth model act as jury and rank which one sounds most human.

Human or Model?

Strip the LLM voice

Paste machine-flavoured text. A model rewrites it keeping the meaning but removing the AI-sounding patterns: no em-dash chains, no rule-of-three, no tapestry metaphors, varied sentence lengths, allowed clunky humanity. Output streams live. Local voice scores are computed before and after so you can see the delta.
